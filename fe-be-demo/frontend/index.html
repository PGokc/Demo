网站前后端调用 Demo

通过静态 HTML 页面调用本地 Go 后端 API（统一返回 { code, message, data }）。

提示：如果你在浏览器中在线访问此页面（而不是本地 file://）， 默认后端地址 http://localhost:8080 很可能无法直接访问。 请在本地启动后端，并将其暴露为可访问的 URL 后，在下方输入框中更新后端地址。

后端服务配置

示例：http://localhost:8080 或你自己的远端地址（不需要包含 /api 前缀）。

API 调用操作

健康检查 GET /api/health

检查后端服务是否正常，预期返回 { status: "ok" }。

Echo 接口 POST /api/echo

发送一段 JSON，服务端原样返回并附加 server_time。

查看 Todos GET /api/todos

返回内存中的 todo 列表（id, title, done）。数据在后端重启后会清空。

新增 Todo POST /api/todos

仅 title 为必填字段，done 默认为 false。

使用说明

  1. 在本地终端中进入后端工程目录，执行 go run main.go 启动后端（默认监听 :8080）。
  2. 本地调试前端：可以直接用浏览器打开本页面的 index.html 文件，或通过简单静态服务器（如 npm serve 或其他）在 http://localhost:5173 打开。
  3. 若使用线上部署的静态页面，请确保将后端部署到公网可访问地址，并在顶部输入框中填写完整的 Base URL。
后端接口：GET /api/health，POST /api/echo，GET/POST /api/todos。 统一返回结构 { code, message, data }。
